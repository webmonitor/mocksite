# 2026-11-01：管理后台视觉重做（石墨台面、单一信号灯、预览作为标本窗口）

本次只改 `web/admin/` 的样式与结构，目标页资产、状态内核、场景注册表、管理 API 与所有交互流程保持原样。

## 变更内容

### 色彩与形状

- `styles.css` 重写为一套中性石墨色阶（浅色 / 深色各一份）：页面底色、面板、次级面、文字三级全部来自同一组变量，边框改为文字色 10%（普通描边）/ 22%（控件描边）的细线，不再有彩色边框和彩色渐变。
- 新增 `--signal` 琥珀色，只用于「当前生效」指示灯与错误之外的一处强调；主操作按钮改为墨色填充，不再沿用目标页品牌绿——控制台的绿色与它预览的高校页面撞色，工具和被观测对象分不开。
- 圆角收敛为三档：面板 12、控件 6、标签 4；原来 4/5/7/8/9/10/12/14 与 `999px` 混用。
- 删掉紫色 `--decoy` 变量；场景卡上的「数据变化」改为 11px 常规字重的「影响」前缀，取消 `text-transform: uppercase` 与 0.05em 字距。

### 排版与间距

- 正文 14px、控件高 32px、分区内边距 16/20、场景行 12/14；替换掉 `14.5px`、`1rem 1.1rem 1.1rem`、`0.42rem 0.85rem` 这类零散值。
- 数字、页面路径、revision 统一等宽字体与表格数字，状态不再用发光胶囊表达。
- 所有交互元素补上 150ms 的 `cubic-bezier(0.22, 1, 0.36, 1)` 过渡与统一的 `:focus-visible` 焦点环。

### 布局

- 顶部栏新增 revision 读数（琥珀灯 + 等宽数字）作为全局状态标识；原来同一信息在预览徽章和右下角 facts 里各出现一次，现在只保留一处：场景名进预览标题栏，现行标准与点击次数留在 facts 里。
- 场景列表由独立圆角卡片改为同一张表上的分隔行；每张卡片的实心主按钮改为普通按钮，只有覆盖确认按钮保留墨色主按钮，避免一屏五个高亮按钮压过预览。
- 字段编辑由一张 16 项平铺网格改为四组（标识 / 金额与日期 / 页面状态 / 相邻通知）加正文，组间用细线分隔；字段的 id、校验键与提交载荷不变。
- 预览面板：`DESKTOP_WIDTH` 1180 → 1024，右列宽度改为 `minmax(520px, 52%)`，缩放后页面文字更清楚；预览头合并为一行（页签 + 操作）。

### 修复

- 窄屏（≤1180px）下，预览 iframe 的固定宽度会把整页撑出横向滚动；已为预览容器与右列补 `min-width: 0`、`max-width: 100%`，窄屏取消 sticky。实测 390px 视口下 `document.scrollWidth` 等于视口宽度。

## 未改变

- `web/targets/shared/`（`notice.css`、`notice.js`、附件图标）未改动：目标页仍是原来的高校门户外观，控制台不再模仿它。
- 场景的绝对覆盖语义、覆盖确认、字段校验与失败保留草稿、revision 自增、预览按 revision 重载等行为均未改动。
- 无新增依赖、无 CDN 引用；字体仍是系统字体栈，读数使用 `ui-monospace`。

## 验证

- 在容器内用仓库现有 `web/node_modules` 执行 `tsc --noEmit` 与 `vite build`，均通过（产物写入未纳入版本管理的 `web/dist`）。
- 用 Vite dev server 连接运行中的 `site` 服务（真实 `/_admin` 数据、真实 `MOCKSITE_TOKEN`）在 Chromium 里实测：连接页、场景覆盖确认与应用、字段编辑保存（通知金额 88.80 保存后右侧预览同步刷新，revision 递增）、浅色与深色主题、390px 窄屏无横向溢出。
- 本次未重跑 pytest 与发布镜像构建：本机到容器镜像仓库的连接在本次会话中一度不可用，因此构建与类型检查改为复用本机已有的 Node 容器镜像执行。
